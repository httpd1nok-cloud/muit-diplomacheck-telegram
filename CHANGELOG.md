# v0.3 · Bilingual Telegram DiplomaCheck + optional AI

- /start now prompts for Қазақша or Русский with inline buttons.
- Bilingual menus, document checks, reports and rubric.
- Offline adviser for common diploma questions sourced to the supplied 2020 guide.
- Optional user-consented OpenAI-backed multi-turn chat, with per-user memory held in RAM.
- Raw diploma contents are never forwarded to OpenAI; only brief report errors may be shared with consent.
- Maintains `app.bot_cloud` entrypoint for compatibility with the existing Railway deployment.
- Does not require website, WhatsApp or public HTTP port.
