# MUIT DiplomaCheck — екі тілдегі тегін толық кеңесші (Railway)

Бұл — **МУИТ-тің 18.11.2020 методичкасына сүйенген** қазақша және орысша Telegram-боттың жаңартылған нұсқасы. Бот дипломды PDF/DOCX форматында тексеруді жалғастырады және диплом жазу туралы сұрақтарға егжей-тегжейлі жауап береді.

## Не өзгерді?

- `/start` → **Қазақша / Русский** тілін таңдау бұрынғыдай сақталған.
- Тегін кеңесші енді тек «§6.3 ...» деп шектелмейді. Кіріспе, теория, практикалық бөлім, эксперимент, есептеу, IEEE, сурет/кесте, формула, бет саны, аннотация, қорытынды, қорғау және басқа негізгі бағыттар бойынша қадамдық кеңес береді.
- IoT/Smart City/LoRaWAN, Machine Learning, телекоммуникациялар, веб-қосымшалар/бот жобаларына жеке **мысал сценарийлерін** береді.
- Студент тақырыбында IoT бар екенін айтса, сол сессияда келесі сұрағына («қандай есептеулер?») IoT мысалдарын қайта қолданады. `/clear` контексті өшіреді.
- **OpenAI API мүлдем ажыратылған.** Код әдейі `ENABLE_AI_CHAT=true` және `OPENAI_API_KEY` Railway-де қате қалып қойса да сыртқы модельге сұрау жібермейді. `openai` кітапханасы requirements-тен алынды.
- Тексеру нәтижелерін шығаратын қозғалтқыш өзгермеді; 2020 методичканың баға жүйесі мен қателер тексеріледі.

## Нақты шектеуі

Бұл жүйе **үлкен тілдік модель емес**, бірақ дайын бір сөйлемдік FAQ емес: көптеген сұраққа көпқадамды, екі тілдегі әдістемелік нұсқау және тақырыпқа байланысты үлгі шығарады. Әлі белгісіз/өте ерекше тақырыпта бот қосымша мәлімет сұрайды. Метoдичка **жобаның дәл белгілі бір технологиясын міндеттейді** деген жалған тұжырым жасамайды.

Формулалар/эксперимент сценарийлері — инженерлік ұсыныс; ресми университет талабы емес. Нәтижелерді өздігінен ойдан шығармайды. Бұл антиплагиат немесе комиссия бағасы емес.

## Railway-де қазір жұмыс істейтін ботты қалай жаңартуға болады?

**Алдымен бұрынғы кодты сақтап ал** (GitHub-та ескі commit сақталады):

1. ZIP-ті жүктеп, MacBook Finder-да **екі рет басып аш**.
2. GitHub → бұрынғы `muit-diplomacheck-telegram` репозиторийін аш.
3. Жаңартылған файлдарды **сол қалта құрылымымен** репозиторийге енгіз:
   - `app/offline_advisor.py` — **жаңа файл**;
   - `app/knowledge.py`, `app/bot.py`, `app/i18n.py`, `app/ai_advisor.py` — **жаңартылған файлдар**;
   - `requirements.txt` — AI кітапханасы алынып тасталды;
   - `README_KZ.md` — жаңартылған нұсқаулық.
4. GitHub-та **Commit changes** жаса. Браузерде бірдей атаудағы файлдарды алмастыру қиын болса, GitHub Desktop қолдануға болады; басқа папкаға салсаң, Railway ескі кодты іске қосуы мүмкін.
5. Railway автоматты redeploy жасаса, **Deployments → Deploy Logs** тексер. Басқа жағдайда жаңа commit үшін **Redeploy** таңда.
6. Railway → Variables → `ENABLE_AI_CHAT` = `false` болсын. **`OPENAI_API_KEY` айнымалысын өшір**, ал OpenAI API Keys сайтынан сол кілтті **Revoke** етуге болады. `OPENAI_MODEL` және `AI_DAILY_LIMIT` енді қажет емес. `TELEGRAM_BOT_TOKEN` бұрынғыша сақталсын.
7. Telegram-да `/start` → Қазақша → «Диплом бойынша кеңес» → мына сұрақты жазып көр:

```
Менің диплом тақырыбым — IoT Smart City желісін жобалау. Практикалық бөлімге қандай есептеулер мен эксперименттер енгізу керек?
```

Бот **LoRaWAN, PDR, эксперимент сценарийлері** және §6.3, §6.16 тәрізді нақты дереккөз тармақтарымен жауап беруі тиіс.

> Қауіпсіздік: `.env` немесе токендерді GitHub-қа **жүктеме**. Бұл архивте тек `.env.example` бар. Егер код GitHub-та **Public** болса, жоба коды бәріне көрінеді. Құпия API кілті кодта болмауы керек.

## Жергілікті тест (міндетті емес)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
python -m pytest -q
```

Railway-дің Dockerfile іске қосу командасы бұрынғыдай: `python -m app.bot`. Бұрынғы `app.bot_cloud` entry point да сақталған.

## Сақталатын шығын

OpenAI-ға **сұрау жіберілмейді және API төлемі есептелмейді**. Бірақ бот Railway серверінде жұмыс істегендіктен, Railway-дің жеке тарифі/лимиті бар — соны бөлек қадағалаңыз.
