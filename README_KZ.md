# MUIT DiplomaCheck — Telegram 🇰🇿 Қазақша / 🇷🇺 Русский + диплом кеңесшісі

**Мақсат:** Railway-де қазір жұмыс істеп тұрған Telegram-ботты жаңарту, WhatsApp пен сайтты қолданбай. Боттың аты мен Telegram сілтемесі, BotFather токені **өзгермейді**.

## Қандай жаңалық бар?

- `/start` басқанда **«🇰🇿 Қазақша» / «🇷🇺 Русский»** батырмалары пайда болады; интерфейс, тексеру қорытындылары, JSON есебі және кеңесші сол тілде жұмыс істейді.
- `/language` арқылы тілді кез келген уақытта өзгертуге болады. Railway қайта іске қосылғанда тіл таңдауы жадта сақталмай қалуы мүмкін — `/start` арқылы қайта таңдайды.
- Әдеттегідей `.pdf` немесе `.docx` жіберіп, МУИТ методичкасы бойынша автоматты диагностиканы алады (20 МБ, 400 PDF бетке дейін). Нәтиже — **алдын ала сәйкестік пайызы**, университеттің ресми 100 балдық бағасы емес.
- **💬 Диплом бойынша кеңес:** стандартты жағдайда методичкадан нақты тармақтарды еске салатын тегін FAQ. 125 бөлім/тармақ мәтіні 2020 жылғы PDF-тен үзінді ретінде индекстелген. Мысалы: «Кіріспеге не жазамын?» / «Как оформить IEEE?» / «Қорғау қанша минут?».
- **Нағыз AI сұхбат** тек `ENABLE_AI_CHAT=true` және `OPENAI_API_KEY` қосылса іске қосылады. Студент «💬 ...» басқан соң деректі OpenAI-ға жіберуге **жеке келісім** береді. Диалогтың алдыңғы 5 жұбы жадта сақталады (Railway restart-та өшеді), `/clear` арқылы тазартылады.
- Құжат файлдары AI-ға жіберілмейді. AI-ға студенттің сұрағы, шағын әңгіме тарихы, методичка үзінділері және (егер болса) соңғы тексерудің **қате туралы қысқа есебі** ғана жіберіледі. AI провайдерінің дерек өңдеу саясатын ескеріңіз.

## 1. GitHub-қа жаңартылған кодты салу (MacBook-тан)

1. Бұрынғы жұмыс істеп тұрған Railway жобасын **өшірме**. Алдымен осы ZIP архивін MacBook-қа жүктеп, екі рет басып аш.
2. GitHub-та **бұрынғы** `muit-diplomacheck-telegram` репозиторийіне кір. Құпия деректер болмағанына көз жеткіз: `.env` файлын жариялама.
3. **Add file → Upload files** аш. **Жаңа папканың ішіндегі файлдар мен қалталарды** (соның ішінде `Dockerfile`, `requirements.txt`, `app`, `config`, `reference`) жүкте; **ZIP файлының өзін емес**. Егер GitHub браузердегі upload бірдей атаулы файлдарды алмастырмаса, төмендегі Terminal/Git жолын қолдан.
4. **Commit changes** бас. Railway GitHub өзгерістерін автоматты deploy жасаса, логтарды тексер. Егер өзгертулер әлі қолданылмаса, Railway-де **Deploy** бас.

**Сенімдірек Git командалары** (MacBook-та `git` орнатылған және GitHub рұқсаты берілген болса):

```bash
cd ~/Downloads
# ZIP ашылғаннан кейін оның ішіндегі MUIT_DiplomaCheck_KZ_RU_AI қалтасы осында болуы керек.
git clone https://github.com/httpd1nok-cloud/muit-diplomacheck-telegram.git
# Бұрынғы репозиторийдің ішіне жаңа нұсқа файлдарын көшіреміз (токен/venv көшірілмейді):
rsync -av --exclude='.env' --exclude='.venv/' --exclude='.git/' --exclude='__pycache__/' --exclude='.pytest_cache/' \
  MUIT_DiplomaCheck_KZ_RU_AI/ muit-diplomacheck-telegram/
cd muit-diplomacheck-telegram
git status
# Өзгерістер тізімін қарап шыққан соң:
git add app config reference Dockerfile requirements.txt requirements-dev.txt .env.example .gitignore .dockerignore README_KZ.md CHANGELOG.md
git commit -m "Add bilingual KZ/RU diploma adviser"
git push
```

Егер GitHub жүктеуінде `MUIT_DiplomaCheck_KZ_RU_AI/` деген артық бір сыртқы папка пайда болса, Railway `Dockerfile` таба алмайды. Репозиторийдің **түбірінде** `Dockerfile` тұруы керек.

## 2. Railway Variables — міндетті және қосымша

Railway → өзіңнің бұрынғы Project → Telegram service → **Variables**.

| Variable | Мәні | Қашан керек? |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Бұрынғы BotFather токені | Міндетті, бұрыннан бар болса өзгертпе |
| `ENABLE_AI_CHAT` | `false` | Бірінші тегін сынаққа, AI өшірулі |
| `OPENAI_API_KEY` | Жеке API кілт | Нағыз AI сұхбат қажет болса |
| `OPENAI_MODEL` | `gpt-4.1-mini` | OpenAI жобаңызда қолжетімді модельді көрсетіңіз |
| `AI_DAILY_LIMIT` | `100` | Сервердегі барлық AI жауаптарына тәуліктік лимит (рестартта қайта басталады) |
| `ALLOWED_TELEGRAM_USER_IDS` | Бос немесе Telegram numeric ID тізімі | Пайдаланушыларға қолжетімділікті шектеу |

**Нағыз AI-ды қосу:** OpenAI API жобасында жеке API кілті және жеткілікті баланс керек. ChatGPT Plus жазылымы **API төлемін автоматты қамтымайды**. Қауіпсіздік үшін алғашқы күндері `ALLOWED_TELEGRAM_USER_IDS` арқылы тек өз нөмірлі Telegram ID-іңе рұқсат беріп, API шығын лимитін провайдер аккаунтынан да қой. Алдымен `ENABLE_AI_CHAT=false` режимінде тілді/файлды тексер. Кейін API кілтті GitHub емес, тек Railway Variables ішіне жаз, `ENABLE_AI_CHAT=true` деп өзгертіп Deploy жаса. API модельінің атауы, қолжетімділігі және тарифтері ауысуы мүмкін; өз аккаунтыңда тексер.

API кілтсіз **еркін генеративті диалог жұмыс істемейді**, бірақ МУИТ методичкасына сүйенген тегін сұрақ-жауап қалады. Бұл айырмашылық боттың ішінде анық көрсетіледі.

## 3. Деплойды тексеру

Railway-дегі **Deploy Logs**:

```text
MUIT DiplomaCheck KZ/RU worker starting. AI configured: False
```

Бір ғана Telegram worker іске қосылуы керек; егер локалды MacBook-бот әлі жүрсе, `Control+C` арқылы тоқтат (әйтпесе `409 Conflict`). Railway-дегі `Start Command` ескі `python -m app.bot_cloud` болса да жаңа архив оны қолдайды; жаңа `Dockerfile` `python -m app.bot` командасын іске қосады.

Telegram-да өз ботыңа `/start` жібер: екі тіл көрінуі керек. Қазақшаны таңда, «Кіріспеге не жазамын?» сұра. Орысшаны таңда, «Как оформить список литературы?» сұра. Word/PDF тест файлын екі тілде тексер. MacBook-ты жауып телефоннан тест жаса.

## 4. Маңызды шектеулер

- Тек МУИТ-тің **18.11.2020** нұсқауы енгізілген. Қазіргі талаптардың соңғы редакциясын университеттен тексеру қажет.
- PDF скандарын OCR қолданбайды. DOCX форматында нақты бет саны сақталмайды, сондықтан бет санын дұрыс тексеру үшін PDF жүктеңіз.
- Бот плагиатты анықтамайды және университеттің ресми қорғау бағасын қоймайды.
- Құжат Telegram мен Railway сервері арқылы өтеді; тексеру аяқталғаннан кейін өңдеу файлы уақытша каталогтан өшіріледі. Сыртқы AI-ға толық файл жіберілмейді.
- Railway-дің ағымдағы тарифі/биллинг лимиттері аяқталса, бот та тоқтауы мүмкін.
- API кілтті және Telegram токенін ChatGPT-ке, GitHub-қа немесе скриншотқа жарияламаңыз.
- Кеңесші жауаптары ғылыми жетекші мен кафедра шешімінің орнына жүрмейді.
